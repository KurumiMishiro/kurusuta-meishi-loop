# 名刺動画 1ループ加工（kurusuta-meishi-loop）

クルスタ（ティンクルスターナイツ）のプロフィール画面で名刺を表示したまま撮った画面録画から、名刺の部分を自動で切り抜いて、自然につながる1ループの無音動画（MP4）を作るWebツールです。

**公開URL:** https://kurumimishiro.github.io/kurusuta-meishi-loop/

> 非公式のファンメイドツールです。運営・開発元とは関係ありません。

## 使い方

1. **動画を選ぶ** — 名刺を表示したまま録った画面録画（MP4 / MOV）を選び、「読み込みを開始する」をタップします。
2. **範囲と区間を確認** — 名刺の範囲とループ区間が自動で検出されます。特殊枠の場合は「枠の種類」で「特殊枠」を選んでください。必要ならドラッグやスライダーで微調整できます。
3. **書き出し** — 「ミュートMP4を書き出す」を押し、「動画を保存する」または「ダウンロード」から保存します。

### 録画のコツ

- 名刺を表示したまま **5〜15秒ほど** 録画するのがおすすめです。
- 長い動画や高解像度の動画は、解析・変換に時間がかかったり、スマホではメモリ不足になったりすることがあります。

## プライバシー

選択した動画は **この端末の中だけで処理** します。サーバーへの送信、履歴やログの保存は行いません。
（MP4変換用のライブラリ ffmpeg.wasm のみ、初回に jsDelivr から読み込みます。）
